# مستقل بوت — Mostaql Telegram Bot

بوت تيليغرام يراقب منصة مستقل ويُرسل إشعارات فورية بالمشاريع البرمجية الجديدة مع عروض مُولَّدة بالذكاء الاصطناعي.

---

## المميزات

- 🔔 مراقبة تلقائية كل 30 ثانية لمشاريع البرمجة
- 📋 عرض كامل لتفاصيل المشروع (ميزانية، مهارات، مدة التنفيذ)
- 👤 بيانات صاحب المشروع (معدل التوظيف، المشاريع المفتوحة، إلخ)
- 🤖 توليد عروض احترافية بالذكاء الاصطناعي (Gemini)
- ❓ الإجابة على أسئلة قبل التقديم تلقائياً (عند تفعيل الحساب)
- ⏸ إيقاف/استئناف المراقبة من داخل التيليغرام

---

## متطلبات التشغيل

- Python 3.11+
- حساب على Telegram وبوت جديد من @BotFather
- مفتاح API من [Google AI Studio](https://aistudio.google.com)
- (اختياري) حساب على موقع مستقل للوصول للبيانات الكاملة

---

## الإعداد والتشغيل

```bash
# 1. استنساخ المشروع وتثبيت المكتبات
cd MostaqlTelegramBot
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 2. نسخ ملف الإعدادات وتعبئته
cp .env.example .env
# ثم افتح .env وأضف بياناتك

# 3. تشغيل البوت
python main.py
```

---

## ملف الإعدادات (.env)

| المتغير | الوصف | إلزامي؟ |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | توكن البوت من @BotFather | ✅ |
| `TELEGRAM_CHAT_ID` | معرّف حسابك (@userinfobot) | ✅ |
| `MOSTAQL_EMAIL` | إيميل حساب مستقل | اختياري |
| `MOSTAQL_PASSWORD` | كلمة مرور مستقل | اختياري |
| `GEMINI_API_KEY` | مفتاح Google Gemini API | اختياري |
| `POLL_INTERVAL_SECONDS` | فترة الفحص بالثواني (افتراضي: 30) | اختياري |
| `BASE_PROPOSAL_PROMPT` | وصف خبراتك ومهاراتك للـ AI | اختياري |

## هيكل المشروع

```
MostaqlTelegramBot/
├── main.py              # نقطة الدخول الرئيسية
├── config.py            # إعدادات من .env
├── bot/
│   ├── handlers.py      # أوامر التيليغرام
│   └── keyboards.py     # أزرار inline
├── scraper/
│   ├── models.py        # نماذج البيانات
│   └── mostaql.py       # الـ scraper الرئيسي
├── ai/
│   └── proposal.py      # مولّد العروض بـ Gemini
├── db/
│   └── database.py      # قاعدة بيانات SQLite
└── scheduler/
    └── job_monitor.py   # دورة المراقبة + الإشعارات
```

## الأوامر المتاحة في التيليغرام

| الأمر | الوظيفة |
|---|---|
| `/start` | رسالة ترحيب + معلومات البوت |
| `/status` | إحصائيات + أزرار الإيقاف/الاستئناف |
| `/pause` | إيقاف مؤقت للمراقبة |
| `/resume` | استئناف المراقبة |

## ملاحظات

- **نمط عام (Public Mode):** يعمل بدون بيانات مستقل — يُرسل المشاريع مع البيانات العامة فقط.
- **نمط مصادق (Authenticated Mode):** بعد إضافة بيانات مستقل، يُضيف معدل التوظيف والأسئلة.
- **الـ AI اختياري:** إذا لم تُضف مفتاح Gemini، سيُرسل البوت الإشعار بدون عرض تلقائي.
